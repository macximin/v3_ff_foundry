## 4. BLOCK (라우팅) — 서오 라우팅 일반화 (4작째 판정)

### A. 사이클 유형 — 강동호 확인분
- **저점 진입·줍기:** ✅ 동일(폐물 부서 재설계 → 좌천 알짜 씨네박스 줍기). 단 **무장 수단이 게임시스템.**
- **정보우위 베팅·매집:** ✅ 동일하되 **~ep80 후행 해금**(서브프라임 공매도). 서오 ep01 즉발과 결정적 차이.
- **격변 폭발 한 방:** ◐ ep80+ 서브프라임=강동호의 격변(우리 IMF 대응). 단 **ep80 시점엔 빌드업 중**(45달러 붕괴 대기) — 폭발 착지 디테일(서오 메모지·계단·숫자캐치볼급)은 본 구간서 미확인. *강동호 격변 착지법 풀뎁스는 ep83~90 추가 채굴 필요(이번 DIGEST 범위 밖).*
- **적 응징·되갚기:** ✅ 동일(형제 면전 기싸움 + 적 자충수 적재).
- **세력 장악:** ✅ 동일(씨네박스 부사장→사장 얼굴마담 세우고 실권 장악 ⓚ81, 부서→계열사 스케일업).
- **거래 설계:** ✅ 동일(파르네세 앵커링). 단 **스킬카드 보조**가 강동호 고유.

### B. 라우팅 패턴 — ★서오 "공통 4종" 4작째 검증 결과
1. **매 화 가시 페이오프(셋업-only 0):** ✅ **장르 공통 확정** + 강동호는 **퀘스트 보상 레이어로 이중 보강**(사건성과 + 게임수치/코인). → 서오 추정 유지, 강동호가 *강화 변주* 제공.
2. **이중시점 상시 깔기(퇴장후 고평가/적 저평가):** ✅ **장르 공통 확정**(박재민 유적 적 POV + 회장 부재자 고평가). → 4작째 통과, **진짜 장르 공통.**
3. **부 단위 주력 사이클 이동(진입→베팅/장악):** ✅ **장르 공통 확정** — 강동호도 명확: **1부 사내정치(마케팅본부) → 2부 계열사 장악(씨네박스) → 3부 글로벌 금융·미디어(헤지펀드·워싱턴포스트 ep98~102).** 화제목 라인 스캔으로 ep50 상하이·ep61 인수·ep80 공매도·ep101 워싱턴포스트 인수 확인 = **사내→국내계열→글로벌 단계 상승** 또렷.
4. **slow-burn 빌런 × 화 줍기 × 아크 베팅 믹스:** ✅ **장르 공통 확정**(박재민 빌런[부] + 인재/계약 줍기[화] + 후반 공매도 베팅[아크]).

→ **★판정: 서오가 "3작 공통이나 강동호 확장 전 1차 관찰"로 유보했던 라우팅 4종이 4작째에서 전부 재현 = 장르 공통(서오 버릇 아님)으로 승격.**

### C. ★반대로, "서오 버릇으로 갈린" 것 (강동호서 다르거나 부재)
- **엣지 엔진:** 서오=ep01 미래지식 즉발. 강동호=게임시스템 + 미래지식 후행 해금. → **"회귀자 ep01 전능 무장"은 서오(및 일부) 버릇, 장르 필수 아님.**
- **격변 폭발 착지 5법(메모지·계단·숫자캐치볼):** 서오 **독식 ep78-86 단독 풀뎁스**라고 block_bank가 이미 유보 → 강동호 ep80 구간선 그 수준 디테일 미확인. **독식만의 디테일일 가능성 강화**(4작째도 반증 못 함).
- **응징 신조 "원한 100배"·불확실성 손떨림:** 강동호 본 구간선 부재. 서오(특히 마법) 색채로 갈림.
- **per-chapter 보상 메커니즘:** 서오=사건성과. 강동호=게임수치/가챠. → **"per-chapter 페이오프"는 공통이나 *수단*은 작가별**(서오 사건, 강동호 게임UI).
