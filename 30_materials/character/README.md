## 주인공 작동 원형

- `character_bank.md`: 성격·목소리·첫등장·미니아크·관계 함수 원형.
- `protagonist_operating_archetypes.md`: 성공작 주인공의 현실 직업·반복 경제행동·축적물·최종 거물상 색인.
- `protagonist_operating_identity_template.md`: 한 작품이 기준 작동 원형 하나를 골라 Living Spine 전에 실행하는 build evidence.

성격과 경제적 작동을 한 카드에 평균내지 않는다. 주인공 작동 정체성은 본체 원형 하나가 책임지고, 기존 캐릭터 뱅크는 목소리·관계·인간 후폭풍을 보강한다.
