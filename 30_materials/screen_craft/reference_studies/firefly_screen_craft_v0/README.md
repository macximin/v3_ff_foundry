# Firefly Screen Craft Reference Pack v0

상태: `reference_only · no_story_authority`

영상문법을 관찰하기 위한 비권위 학습팩이다. 생산 대본, 작품 canon, 보편 craft rule을 소유하지 않는다.

## 위치

- Google Drive root: `https://drive.google.com/drive/folders/1OF1foYeiErgimaeAXtv17sF-MbuvyGfL`
- animation folder: `01_animation_screenplays` — PDF 25편
- produced short folder: `02_produced_short_screenplays` — PDF 5편
- index folder: `00_index`

## 계약

- `authority: none`
- `learning_scope: reference_only`
- production packet 자동 첨부 금지
- 작품·format·universal rule 자동 승격 금지
- 관찰 결과는 `attempt_only` 또는 `format_profile` 후보로만 시작
- 라이선스 판정과 차단은 이 시스템의 소관이 아님
