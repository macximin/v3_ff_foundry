# 저승식당 4화 후보 원고 작성 요청

첨부한 현재 누적 후보 원고 1~3화와 캐논 노트, 초반 5아크 계획을 모두 실제로 읽고 이어서 써 주세요.

## 현재 연속성

- 1화의 딸 이름은 `강소율`, 현재 나이는 만 열한 살입니다. 세 해 전 아내가 사망했을 당시 소율은 여덟 살이었습니다.
- 도윤은 삼도식당의 영업 주체로 체감 삼 년을 근무하면 생환이 확정됩니다.
- 이승 수술실 시간은 멈춰 있습니다.
- 손님 수·완식 수·성공 여부는 삼 년을 가감하지 않습니다.
- 서하진과 식당의 공주는 별도 인물입니다.
- 공주의 본명 `연화`는 아직 공개하지 않습니다.
- 3화는 혀가 없는 중년 남자가 목패로 `[그래도 맛을 느낄 수 있겠소?]`라고 묻는 장면에서 끝났습니다.

## 4화의 역할

- 4~6화짜리 `혀 없는 손님` 아크의 첫 화만 씁니다. 이번 화에서 손님을 완전히 해결하거나 떠나보내지 마세요.
- 도윤은 먼저 강한 간·열기·향 또는 다른 감각 자극으로 실제 반응을 끌어냅니다.
- 그러나 `느끼게 만드는 것`, `맛있게 만드는 것`, `그 사람이 원한 한 끼`가 서로 다르다는 실패를 겪어야 합니다.
- 첫 시도가 기술적으로 완전한 실패일 필요는 없습니다. 손님은 무언가를 분명히 느끼지만, 그것을 자신의 마지막 식사로 선택하지 않습니다.
- 공주는 정답을 설명하는 통역기가 아닙니다. 목패와 선택지를 정리하여 손님이 직접 선택하거나 거부할 수 있게 만드는 역할을 시작합니다.
- 도윤과 공주가 함께해야 주문 자체가 완성된다는 방향만 진전시키고, 정확한 답과 배웅은 5~6화에 남기세요.
- 요리사의 관찰·조리 판단과 저승 재료의 물성을 중심 재미로 유지하세요. 설정 설명과 교훈 독백은 최소화하세요.
- 1~3화의 비교적 빠른 호흡을 유지하고, 과도하게 장면을 늘리거나 같은 의미를 반복하지 마세요.

## 금지

- 1~3화 재작성
- 1,095일, 하루 적립, 만족도, 귀환 게이지
- 생환 가능성을 다시 불확실하게 만들기
- 소율 삭제 또는 나이·성 변경
- 서하진과 공주 합치기
- 공주의 본명 공개
- 혀 이외의 감각을 쓰면 곧바로 성공하는 직선 해결
- 새 장기 악역·저승 우주론·장기 비밀 확정

## 출력

- 수정 설명, 설계안, 자기평가 없이 바로 저장 가능한 4화 전체 후보 원고만 출력하세요.
- 분량은 기존 2~3화와 비슷한 호흡으로 약 6,000~8,000자 안팎을 목표로 하세요.
- 장면 전환은 반드시 `***`를 문자 그대로 사용하고 `---`는 쓰지 마세요.
- 제목이나 마크다운 코드펜스 없이 원고 본문만 출력하세요.
