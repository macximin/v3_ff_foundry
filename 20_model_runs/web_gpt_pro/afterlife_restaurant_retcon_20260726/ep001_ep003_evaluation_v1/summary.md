# 저승식당 ep001–ep003 재평가 요약

## 판정

- `재수정 필요`
- `78/100`
- 구조와 사건 순서는 유지 가능
- 4화 전 압축 폴리시와 수치·소품 연속성 잠금 필요

## 구조적 강점

- 도윤의 생존 욕망이 매 화 실제 선택과 실패를 만든다.
- 연화가 설명자가 아니라 권한과 책임을 가진 공동 운영자로 작동한다.
- 첫 손님의 개인 오독, 한명옥의 운영 체계상 삭제, 운영 규칙 재구축으로
  실패 규모가 단계적으로 확장된다.
- 요리 전문성이 진단, 경제적 가치 발견, 운영 공정 개선으로 사건을
  움직인다.
- 1화와 3화의 문턱 반응이 다른 형태를 가지면서 같은 엔진으로 읽힌다.
- 폐기 설정은 재혼입되지 않았다.

## 반드시 고칠 항목

아래 수치·소품·표현 오류는 Web GPT 평가만 옮긴 것이 아니라 저장된
후보 원고에서 다시 찾아 존재를 확인했다.

1. 2화의 손님 수, 전병 수, 매출, 명옥 포함 여부, 잔여 재고를 하나의
   수치 모델로 재계산한다.
2. 그 결과에 맞춰 3화 시작 자금과 잔액을 맞춘다.
3. 3화 예약패의 소유 위치, 같은 날의 `전날`, `딸랑` 뒤
   `종은 울리지 않았다` 모순을 고친다.
4. 시장 주문과 우선 손님 세 명이 실제로 같은 시간에 충돌하는 마감
   조건을 부여한다.
5. 1화에서 연화가 문턱을 붙든 채 긴 조리와 식사를 버티는 시간 물성을
   보강하거나 해당 구간을 압축한다.
6. 이미 행동으로 드러난 의미를 다시 설명하는 문장을 걷어 내 세 화를
   최소 20% 압축한다.
7. 우선 손님 세 명이 돌아간 뒤 즉시 다시 등장하는 동선을 분명히 한다.
8. 1화의 `그릇로`를 `그릇으로`로 고친다.

## 선택 폴리시

- `직급 안 본다` 농담의 반복 횟수
- 두 번째 문턱 뒤 설거지 농담 앞 여운
- 두 손님의 `자기 몫 후순위` 표현 차별화
- 한명옥 운영 규칙 네 줄의 노출량
- 3화 종료를 생환 미스터리와 운영 압력 중 어디에 더 무겁게 둘지
