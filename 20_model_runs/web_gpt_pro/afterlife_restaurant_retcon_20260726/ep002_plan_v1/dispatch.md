## Prompt

첨부한 세 파일을 읽고, **아직 2화 원고는 쓰지 말고** 새 1화에 이어지는
2화를 어떻게 수정해야 하는지 먼저 비판적으로 설계해 주세요.

현재 새 1화는 기존 2화가 맡던 기관실 손님·국물 요리·첫 배웅·첫 문턱
반응까지 이미 다른 이름과 재료로 완결했습니다. 따라서 기존 2화를
문장만 고치면 사건이 중복됩니다.

검토할 것:

1. 새 1화 직후 2화가 맡아야 할 상업적 역할
2. 기존 2화에서 보존할 장점과 반드시 삭제·교체할 요소
3. 두 번째 손님과 운영 실패를 어떻게 한 엔진으로 묶을지
4. 도윤의 생존 욕망을 유지하면서 첫 성공 양산 시도가 왜 실패하는지
5. 연화가 독립 공동 운영자로 행동할 지점
6. 2화의 시작·중간 반전·클라이맥스·종료 훅
7. 3화가 이어받아야 할 정확한 미완 과제

금지:

- 강소율 또는 대체 가족 동기
- 1,095일, 고정 일수, 누적 점수·게이지
- 첫 손님 아크 반복
- 새 고정 악역이나 장기 진실 확정
- 2화 전체 원고 작성

결과는 2화 수정 설계만 구체적으로 제시해 주세요. 이후 별도 요청에서
이 설계를 기준으로 2화 전체 원고를 작성시킬 예정입니다. 이후 원고의
장면전환 표시는 반드시 `***`를 문자 그대로 사용합니다.
