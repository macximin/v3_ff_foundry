# 저승식당 ep002 전체 수정 요청

## Prompt

좋습니다. 방금 제시한 설계를 기준으로 이제 **수정된 2화 전체 원고만**
처음부터 끝까지 작성해 주세요.

필수:

- 새 1화 직후부터 자연스럽게 이어집니다.
- 한명옥과 공통 시식 전병, 첫 성공의 잘못된 확장, 연화의 영업 중단,
  재고 바닥, 황천장 조달 훅을 방금 설계한 인과대로 구현합니다.
- 도윤은 1화의 교훈을 잊은 것이 아니라 생존과 운영 우선순위 때문에
  명옥의 차례를 알고도 미룬 사람이어야 합니다.
- 대량 조리와 운영 자체를 악으로 만들지 않습니다.
- 연화도 처음에는 운영 확대에 동의했다가 자기 책임을 인정하고 직접
  문을 닫는 공동 운영자로 행동합니다.
- 2화에서는 명옥을 배웅하거나 문턱 반응을 지급하지 않습니다.
- 3화는 쓰지 않습니다.
- 강소율, 대체 가족, 1,095일, 일수 적립, 점수·게이지, 고정 악역을
  넣지 않습니다.
- 장면전환은 빈 줄 사이에 `***` 세 글자를 문자 그대로 사용합니다.
  `---`는 사용하지 않습니다.

출력:

- 기획 설명, 변경 요약, 자기평가, 주석 없이 바로 저장 가능한
  **2화 전체 원고만** 출력합니다.
- 이 결과는 감리 전 후보 원고입니다.
