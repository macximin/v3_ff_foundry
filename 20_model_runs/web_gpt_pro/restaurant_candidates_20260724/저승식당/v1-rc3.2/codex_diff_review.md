# 저승식당 v1-rc3.2 Codex 차분 감리

## 판정

**GO**

`v1-rc3.1` 캐노니컬 재확인에서 남은 두 국소 정합성 결함이 지정 범위 안에서 해소됐다. 사건·숫자·보상·문체·클리프행어 회귀는 없다. `v1-rc3.2`를 정식 BR0 입력으로 사용할 수 있다.

이 판정은 원고 후보의 차분 통과이며 사용자 Adopt 또는 캐노니컬 승격을 뜻하지 않는다.

## 입력과 무결성

- 기준본: `v1-rc3.1/ep001.txt`~`ep003.txt`
- 후보본: `v1-rc3.2/ep001.txt`~`ep003.txt`
- ep001 WebGPT DOM 응답 일치: 종결 LF 제외 정확히 일치
- ep002: 기준본과 바이트 동일
- ep003 WebGPT DOM 응답 일치: 종결 LF 제외 정확히 일치
- 기계 차분:
  - `diff_ep001.patch`
  - `diff_ep003.patch`

## 화별 판정

### ep001 — PASS

변경은 `18:37` 직후 한 문단뿐이다.

> 저승에서 이어지는 대화와 수술실의 시간은 같은 속도로 흐르지 않았다. 이곳에서 한참 말을 주고받는 동안에도 이승에서는 몇 초만 흘렀다.

- `18:42 → 18:40 → 18:37 → 18:34 → 18:31` 숫자 보존
- `18:34` 설명 중 일시 정지 보존
- 계약 성립 뒤 이승 시간 정지와 `18:31` 훅 보존
- 계약 조건 `1명 = 1일`, 필요 귀환 시간 `1,095일` 보존
- 새 능력이나 해결 수단을 추가하지 않고 기존 장면의 두 시간축을 명료화
- 오프닝, 딸 소율, 십 년산 소스, 하진, 첫 손님 진입 훅 회귀 없음

### ep002 — PASS

변경 없음. SHA-256과 바이트 비교가 모두 기준본과 일치한다.

- 김문성 판독
- 출항 기억 오작동과 교정
- 귀항탕
- 빈 그릇과 `맛있소`
- 배웅 완료 1일
- `18:31`
- 첫 매출 6닢과 빈 창고

모두 그대로다.

### ep003 — PASS

변경은 공개 신분 호칭 두 곳과 낮은 목소리 명시 한 곳뿐이다.

1. `공주는 평범한 걸 뼈까지 핥아?` → `평범한 걸 뼈까지 핥아?`
2. `오늘부터 공주가 관리야.` → `오늘부터 네가 관리야.`
3. `정체는 숨기고` 앞에 `나는 공주에게만 들리도록 목소리를 낮췄다.` 추가

- 황천장 군중 앞 공개 호칭 충돌 해소
- 서술자가 공주라고 부르는 문장과 둘만의 대화는 유지되어 독자 정보 손실 없음
- 공주의 시식·계산·줄 관리·운반 코미디 보존
- 최초 매입 1닢, 시식 5개, 판매 25개 × 2닢 = 50닢 보존
- 6:4 정산, 도윤 30닢, 총 35닢, 장보기 17닢, 잔액 18닢 보존
- 정기 공급계약 `날개 30개 + 터진 회혼매 12알 = 10닢` 보존
- 혀 없는 두 번째 손님 훅 보존
