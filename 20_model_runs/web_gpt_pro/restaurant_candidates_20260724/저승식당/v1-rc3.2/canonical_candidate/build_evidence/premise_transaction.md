# Premise Transaction — 저승식당 생환 계약

status: candidate

## Scope

- work / episode / anchor: `afterlife_restaurant / ep001~ep003 / A01`
- 검증할 판매 약속: 망자를 제대로 배웅한 한 사람당 하루를 벌고 `1,095일`을 채우면 도윤이 딸에게 돌아간다.
- 이 전제가 고위험인 이유: 주인공의 생존 목표, 옴니버스 단위, 성장 계량, 결말 시점을 한 숫자가 동시에 지배한다. 규칙이 흔들리면 모든 완식의 가치가 무너진다.
- source / Story Block receipts: `AFR-WL-001`, `AFR-WL-002`, `AFR-WL-003`, `AFR-WL-004`

## Prize value receipt

- 독자가 부를 한 문장 이름: 소율에게 돌아갈 `1,095일`.
- 실제 자산·운용자금·지분 가치: 수술실 `18:31`에서 생환하고 명부에 최소 수명 3년이 추가된다. 각 완식의 하루는 최종 생환 자산의 1/1,095다.
- 현금흐름 또는 반복 수익: 귀환 하루와 별개로 손님 개인의 노잣돈, 장터 판매, 공급계약이 식당 운영자금을 만든다.
- 지배하는 사람·사업·계열사·의사결정: 도윤은 삼도식당 메뉴, 재료 조달, 가격, 재고, 조리 안전, 손님 수용 여부를 결정한다.
- 주인공의 장기 목적에 주는 다음 선택지: 하루가 쌓일수록 귀환이 현실적 목표가 되고, 시설·인력·단체 손님을 통해 처리량을 키울 이유가 생긴다.
- 상대가 지급하면 잃는 것과 지급할 이유: 저승의 명부는 이미 사망 예정인 사람에게 시간을 돌려준다. 대신 도윤은 다음 길로 건너지 못한 망자를 자기 발로 떠나게 해 저승의 미해결 체류를 줄인다. `1,095일` 하한과 완전한 배웅 조건이 값싼 부활을 막는다.
- 이름과 숫자를 지워도 남는 독자용 가치 설명: 죽기 직전의 아버지가 다른 이들의 마지막 식사를 완성한 만큼 딸과 함께 살 시간을 되찾는다.
- 주인공이 잃었을 때 사라지는 구체적 미래: 소율과 먹을 다음 날 아침, 빚을 갚고 식당을 다시 열 기회, 아내에게 했던 “아이를 혼자 두지 않겠다”는 약속.

## Protagonist indispensability

- 판의 기본 위험: 손님도 자기가 무엇을 원하는지 모르고, 재료는 기억을 과하게 깨워 망자를 붙잡을 수 있으며, 실패하면 하루가 적립되지 않는다.
- 조연 전문가가 이미 알고·할 수 있는 것: 서하진은 계약과 망자 규칙을 안다. 공주는 저승 재료명과 시장을 안다. 둘 다 손님의 맛을 진단하거나 조리하지 못한다.
- 주인공만 내린 판단·감수한 비용·바꾼 판: 도윤은 김문성의 출항 기억을 정답으로 본 첫 솥을 폐기하고 귀항의 온기로 바꾼다. 이어 전 재산 중 1닢을 폐재료에 걸고 판매·분배·계약을 설계한다.
- 주인공 행동에서 직접 나온 결과: 빈 그릇, 김문성의 퇴장, 귀환 하루, 6닢, 매출 50닢, 도윤 몫 30닢, 17닢 재고, 18닢 잔액, 정기 공급계약.
- 주인공을 삭제한 반사실 결과: 김문성은 기관실 기억에 붙잡히거나 떠나지 못하고, 박명조 날개와 회혼매는 폐기되며, 삼도식당은 다음 손님을 받을 재료를 얻지 못한다.
- 조연의 성과와 주인공의 성과 귀속: 하진은 판과 보상을 열고, 공주는 정보·시식·계산·질서·운반, 안대 노인은 자리·화로·숯·재료를 제공한다. 진단·조리·가격·분배·재고·계약의 비가역 판단은 도윤에게 있다.

## Defeat transaction

- 주인공이 미리 확보한 계약·증빙·동맹·퇴로: 서명된 명부, 멈춘 회중시계, 삼도식당의 조리 권한, 공주와 하진이라는 규칙 증인.
- 주인공의 강점에서 생긴 합리적인 blind spot: 반복된 신체 기억을 가장 중요한 감정 기억으로 빠르게 환원하는 전문가 과신.
- 적대자가 원하는 것: 고정 적대자는 없다. 불리한 힘은 망각어의 기억 작용, 망자의 미련, 사망 명부의 엄격한 교환 규칙이다.
- 적대자가 실제 보유한 권력·정보·동맹: 명부는 완전한 배웅 전에는 하루를 지급하지 않고, 위험 재료는 과량 사용 시 손님을 과거에 붙잡는다.
- 적대자가 감수하는 비용·노출 위험: 인격적 적대자 비용은 해당 없음. 계약 상대인 저승은 망자 체류를 해소하는 대신 사망자 한 명에게 `1,095일`의 생환 예외를 부담한다.
- 방어를 뚫는 구체적 행동 순서: 도윤이 선원 흔적을 읽음 → 강한 출항 기억을 정답으로 선택 → 망각어를 가열함 → 김문성이 보이지 않는 기관실로 걸어감 → 도윤이 위험을 확인하고 솥을 폐기함.
- 주인공이 즉시 막거나 떠날 수 없는 이유: 실패하면 소율에게 돌아갈 수 없고 손님은 미련에 붙잡힌다. 조리를 중단하는 것이 안전한 퇴로가 아니다.
- 패배 뒤에도 주인공의 유능함을 보존하는 잔여 자산·증거·사람: 그는 오작동을 즉시 판독하고 손실을 감수해 전량 폐기한 뒤, 반복 기억과 소중한 기억을 구분하는 더 높은 진단으로 교정한다.
