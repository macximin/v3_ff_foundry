# 기사식당 BR1 — plan court + plan-aware compare

## 판정

```yaml
verdict: pass
blocking_defect: none
owner_decision_required: true
canonical: false
```

독립 BR0가 계획서 없이 복원한 핵심은 `독립과 폐허 선택 → 권력보다 원칙 우위 → 종속 대신 계약`이다. 역복원한 Pitch와 Story Plan도 같은 축을 가진다. plan_closed_loop, 표면 이탈, 치명 산술 오류는 발견되지 않았다.

> BR0 마지막 줄의 `P0 (수정 없이 즉시 연재...)`는 심각도 용어를 반대로 쓴 표기 오류다. BR0 본문은 “치명적인 오류는 발견되지 않았다”고 명시하므로 이 BR1에서는 `blocking_defect: none`으로 정규화한다.

## BR0 고정값

- 첫 기억 물성: 황실 붉은 인장이 찍힌 하르벤 영지권 문서, 정제된 화염초.
- 실제 선택: 황녀의 금화·작위보다 폐허 고향의 완전한 소유권 선택.
- 실제 보상: 북부대공과 기사단이 카일의 식당 규칙을 따르고, 고용 제안이 군납·도로·창고 계약으로 바뀜.
- 카일 삭제 반사실: 아델린 감각 회복, 북부군 급양 개선, 하르벤 재건이 모두 성립하지 않음.
- 다음 압력: 30일 안의 생산·교육·공사와 첫 1,500그릇 인수, 황실 손님.
- BR0 결론: `pass`.

## Premise Transaction / Character Court

- 보상 실질가치: 토지·식당·가격·생산수단·도로·창고·현금흐름·다음 선택이 남는다.
- 주인공 불가결성: 황녀·아델린·하르트·케른은 권한·검증·자원을 제공하지만 문서·조리·공정·배식·가격·계약 구조는 카일이 결정한다.
- 합리적인 방어: 원본 문서, 정가, 추가 섭취 금지, 장부, 표본 검수, 불량 교환, 귀책별 해지·선금·공사비를 서면화한다.
- 상대 비용: 북부는 대금·도로·창고·현지 재료·검수를, 카일은 생산·품질·교육·교환·납기·귀책 비용을 부담한다.
- actor logic: 이세라의 소유욕, 아델린의 실리, 하르트의 안전 검증, 케른의 군수 통제가 각자 가진 권한과 비용으로 행동한다.
- verdict: `pass`.

## 반복·호흡

- ep002는 성공 인증 반복을 최소 압축했다.
- ep003의 핵심 숫자는 `36,000`, `400`, `15일마다 24회`를 협상 구간에서 한 번씩만 완전 제시한다.

- verdict: `pass`.
