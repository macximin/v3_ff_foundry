# Premise Transaction — 기사식당의 독립 거래

status: candidate

## Scope

- work / episode / anchor: `knights_restaurant / ep001~ep003 / A01`
- 검증할 판매 약속: 황녀의 포상을 자기 땅으로 바꾸고, 거물의 고용 제안을 자기 식당의 상호 책임 거래로 바꾼다.
- 고위험 이유: 소유권·전문성·신분 역전·사업 성장이 이 거래에 함께 걸린다.

## Prize value receipt

- 독자가 부를 이름: 내 땅, 내 식당, 내 규칙, 내 계약.
- 실제 가치: 하르벤 토지권과 원본 문서, 식당 운영권, 도로, 카일 소유 창고, 1년 36,000그릇 공급·40금화 교육, 총액 400금화.
- 현금흐름: 한 그릇 정가, 월 2회 납품 인수 대금, 교육 완료 대금.
- 통제권: 카일이 메뉴·안전·가격·생산·고용·공급 여부를 정한다.
- 다음 선택: 선금 200금화를 작업자·설비·재료·포장·마차에 배치해 혼자 운영하는 식당을 생산 조직으로 바꾼다.
- 상대 지급 비용: 북부는 대금·도로·창고·현지 재료·검수 인력을 부담하고, 카일은 품질·교환·납기·교육·귀책 해지 비용을 부담한다.
- 이름과 숫자를 지워도 남는 가치: 권력자의 소유물이던 사람이 자기 일터와 생산수단, 가격과 책임 범위를 스스로 정한다.

## Protagonist indispensability

- 판의 위험: 황녀의 포상은 소유권이 불명확할 수 있고, 아델린의 감각 회복은 과잉 치료·종속·특혜로 이어질 수 있으며, 36,000그릇은 혼자 만들 수 없다.
- 조연이 할 수 있는 것: 황녀는 포상을 승인하고, 아델린은 북부 자원과 계약 권한, 하르트는 의학 검증, 케른은 군수 수치와 인수를 담당한다.
- 카일만의 판단: 토지 문구를 반려하고 원본을 확보한다. 아델린의 추가 주문과 과한 사례금을 거절한다. 50인 조리·공정 배식을 설계하고 고용 대신 상호 계약을 제안한다.
- 직접 결과: 법적 토지권, 첫 매출, 공개 판단권, 군납·교육 계약, 도로·창고, 선금과 생산 책임.
- 삭제 반사실: 카일이 없으면 아델린의 결핍은 안전하게 조리되지 않고, 기사단 급양은 개인 기적에서 반복 생산으로 전환되지 않으며, 하르벤은 폐허로 남는다.

## Defeat transaction

- 정상 방어: 토지 문서 원본, 정가, 장부, 인수 기준, 검수, 교환, 귀책별 해지와 비용을 서면화한다.
- 강점의 blind spot: 카일은 개인 판단과 현장 통제에 능하지만 반복 생산을 타인에게 위임해 본 적은 없다.
- 불리한 힘: 생산량, 작업자 숙련, 공급 지연, 겨울 도로, 품질 편차, 황실의 소환.
- 비용: 첫 납품 실패 시 교환·대금 미지급·계약 해지·선금 상환·창고 미상각 비용이 발생한다.
- 유능함 보존: 실패하더라도 토지권, 식당, 장부, 첫 성공의 조리 원리와 협상 경험은 남는다.
