# Multi-provider planning records

These are saved planning candidates and evidence from four runs dated
2026-09-06 through 2026-09-08. Git archival does not approve a candidate,
change canon, restart a paused run, or publish anything.

The archive includes input documents, saved plans, candidate packets,
structured execution and publication receipts, usage observations, and
operator stop records. A recorded publication receipt describes that past
readback; it is not a fresh verification of the live service.

Raw process logs, browser snapshots, session exports, job descriptions,
process-group records, and controller state remain in the local checkout.
References to those files or host-specific paths in a receipt may therefore
require the original machine. No raw file was deleted during archival.

The 2026-09-08 Git closeout verified all 17 candidate packet body hashes and
the four saved input hashes. This checks byte consistency, not story quality,
human approval, or whether a stopped route completed later.
