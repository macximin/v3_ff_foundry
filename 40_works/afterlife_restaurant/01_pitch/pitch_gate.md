# 저승식당 pitch gate

- [x] 도윤의 생환 동기는 딸 소율에게 돌아가는 것이다.
- [x] 삼도식당에서 체감상 삼 년을 채우면 생환은 확정된다.
- [x] 저승에서 삼 년이 지나도 이승의 수술실 시간은 움직이지 않는다.
- [x] 손님 수·완식 수·수명 지급·점수·게이지로 삼 년을 환산하지 않는다.
- [x] 서하진과 공주는 별개 인물이다.
- [x] 공주의 본명 `연화`는 1~3화에서 공개하지 않는다.
- [x] 김문성의 귀항탕, 6닢, 빈 창고가 2화의 결산이다.
- [x] 황천장 폐재료 상품화·장보기·반복 공급 약속과 혀 없는 손님이 3화의 성장·종료 훅이다.
- [x] 저승의 세부 시간 계산과 우주론은 열어 둔다.
