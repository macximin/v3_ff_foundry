# Stage Context Contract — 폭군식당

이 폴더의 Frozen Pitch와 Story Plan은 장기 설계 권위다. 원고 후보는 `20_model_runs`의 생산 증거이며, 오너의 명시적 채택 전에는 정본이 아니다.

1. 검증 가능한 사실은 source packet, build evidence, 채택된 Frozen Pitch에서만 가져온다.
2. `04_manuscript`와 `08_state`는 오너가 정확한 원고 후보를 채택할 때까지 전진시키지 않는다.
3. 다음 회차를 설계할 때는 직전 확정 Narrative State, 활성 B-Arc, Character Court, Premise Transaction을 함께 확인한다.
4. 새 설정은 즉시 자산·관계·정보·위험 중 하나를 바꾸는 장면으로 회수한다.
5. 외부 재료나 궁정 규칙은 실제 조달·조리·계약의 비용을 동반해야 한다.
